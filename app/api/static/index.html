Architecture

Live (teal): 1 a stored match is prepared, 2 replayed into Kafka second by second, 3 read by the Live page (about half a second later), 4 counted by Spark in 5-minute windows, 5 shown on the Live page. Stored (purple): 6 every message is kept in Bronze; at the final whistle Dagster builds 7 Silver and 8 Gold, each checked by Soda, and 9 the analysis app reads Gold. The arrows move while it happens.
