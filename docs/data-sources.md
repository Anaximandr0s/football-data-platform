# Data sources

The professor's rule: data is generated by Python scripts (Faker, numpy) **or** comes from open data;
names of people and teams must be fictional.

| Match | Source | Command | Role |
|---|---|---|---|
| `m001` | **Simulated** (`data_gen/sim.py`, seed 42) | `python -m data_gen.ingest_foot --source sim --match m001` | Main match. Satisfies FOO-01 "générer un match complet" with zero external dependency. |
| `m002` | **SkillCorner open data** (real, pseudonymised) | `python scripts/download_skillcorner.py 1925299` then `python -m data_gen.ingest_foot --source skillcorner --match m002 --sc-id 1925299` | Optional. Realistic reference + second match for FOO-09 (comparison). |

**Rule: the platform must work with `m001` alone.** `m002` is a bonus; if it ever causes trouble, drop it.

## Why SkillCorner is compatible
| Course need | SkillCorner | Conversion done in `data_gen/skillcorner.py` |
|---|---|---|
| 22 players, 1 position/s | tracking at 10 fps, extrapolated (every player has a position every frame) | keep 1 frame in 10, only players on the pitch (uses `start_frame`/`end_frame` from `match.json`, so substitutions are handled) |
| Pitch 105 × 68 m | `pitch_length`=105, `pitch_width`=68, origin at pitch centre | `x + 52.5`, `y + 34`, clipped to the pitch |
| `speed_kmh` | **not provided** | computed from 1 Hz positions, 3-point median, capped at 40 km/h |
| ≥ 1000 actions | `dynamic_events.csv`: ~1 050 possessions + ~940 engagements (match 1925299) | `pass`, `shot`, `goal`, `tackle`, `foul`, plus `pressure` (see below) |
| Fictional names | **real names** in `match.json` | player ids → `H01..`/`A01..`, Faker names, team → `HOME`/`AWAY`. No real name is written out. |

## Known differences and limits (be honest in the report)
- **No corner events** in SkillCorner. **Goals** are derived (last shot of a team before its score increases); verified: match 1925299 gives 1 goal (the real result is 0-1).
- `pressure` is an extra event type (pressing actions). Add it to the dbt `accepted_values` test if you load `m002`.
- Real match = 16 players per team in Silver (starters + substitutes), so ids go up to `H16`/`A16`.
  The "22 players per second" check still holds because only on-pitch players are kept.
- ~100 minutes (stoppage time) instead of exactly 90, so `ts` runs to ~6000, not 5399.
- Attack direction flips at half-time in real data; the converter does not normalise it.
- SkillCorner tracking is computer-vision based: about 97 % identity accuracy, so expect small errors.
- Tracking files are **Git LFS (~97 MB per match)**: they are downloaded by script into `data/raw/` and never committed.
- **The tracking part of the converter has been tested only on a synthetic fixture** (the files could not be downloaded in my environment). Run it on a real download before relying on it.

## Where files live
```
data/raw/skillcorner/<id>/        downloaded, git-ignored
data/generated/<match_id>/        players.parquet, tracking.parquet, events.parquet, manifest.json (git-ignored)
data/sample/                      small committed copy of m001 (118k rows, <1 MB) for Person B
```
Format: **Parquet**, columns exactly as in `docs/contrat_donnees.md`.
